# 综合素质评价档案

> 记录成长轨迹，展示全面发展 | 高中综合素质评价材料管理系统

## 📋 项目简介

本项目用于系统化整理和管理高中综合素质评价相关材料，涵盖思想品德、学业水平、身心健康、艺术素养、社会实践五大维度，确保材料真实、完整、可追溯。

> ⚠️ **说明**：因 GitHub 对单个文件大小有限制（建议不超过 25MB），部分体积较大的视频无法直接上传至本仓库。我们已将完整视频存放在外部云盘，各位可通过下方链接自行下载查看。

## 🎯 五大评价维度

### 1️⃣ 思想品德

记录参与党团活动、志愿服务、公益劳动等德育实践，以及守纪、孝敬、感恩、合作等日常表现。

**材料类型：**
- 党团活动证明
- 志愿服务记录（社区服务、赛会保障、环保活动）
- 奖惩记录（三好学生、优秀干部、优秀团员）
- 生活管理材料（守纪、孝敬、感恩、合作相关照片/证明）

---

### 2️⃣ 学业水平

反映学科优势与竞赛参与情况，记录学业成就与学术探索。

**材料类型：**
- 学科竞赛获奖证书
- 学业优秀奖状（单科王、进步奖）
- 学习成果展示

---

### 3️⃣ 身心健康

记录日常锻炼习惯、体育特长、卫生习惯，以及应对困难挫折的成长经历。

**材料类型：**
- 日常锻炼记录（跑操、运动照片）
- 体育比赛获奖证书
- 卫生习惯证明（优秀寝室等）
- 身心成长写实材料

---

### 4️⃣ 艺术素养

展示艺术兴趣特长，记录参与艺术活动的表现与成就。

**材料类型：**
- 艺术活动参与证明（音乐会、画展、摄影展）
- 考级证书（音乐、美术、舞蹈、书法等）
- 艺术类竞赛获奖证书

---

### 5️⃣ 社会实践

记录生产劳动、研学旅行、社会调查、科技创新等实践活动。

**材料类型：**
- 军训证明
- 研学/春游/秋游记录
- 社会调查报告
- 科技创新作品（实物照片、活动报告）
- 勤工俭学证明

---

## ⚠️ 重要说明

### 材料规范

- **真实性**：所有材料必须真实有效，造假将作为高考舞弊处理
- **时效性**：材料时间需与实际情况相符
- **完整性**：每学期每个二级维度最多上传10条，遴选上报5条

### 命名建议

```
维度_活动名称_时间_级别.扩展名

示例：
思想品德_国庆社区服务_2021.10.1-10.7_校级.jpg
学业水平_数学竞赛一等奖_2021.11_市级.pdf
身心健康_校运会100米冠军_2021.11.16_校级.jpg
```
